# Elytra Fly

**Elytra Fly** is a Minecraft mod that allows you to glide for extended periods without using fireworks.

Enjoy longer flights and explore the world from the sky without constantly consuming firework rockets.

## Features

- **Extended Gliding** — Glide for a much longer time.
- **No Fireworks Required** — Maintain your flight without using firework rockets.
- **Simple Toggle** — Enable or disable the feature directly from the mod menu.
- **Lightweight** — A simple feature with minimal configuration.

## How to Use

1. Install the mod using [Preloader Android](https://github.com/LiteLDev/preloader-android).
2. Launch Minecraft.
3. Open the mod menu.
4. Find **Elytra Fly**.
5. Enable the toggle.
6. Equip your Elytra and start gliding!

Once enabled, you can enjoy extended gliding without needing fireworks.

## Requirements

- Minecraft Bedrock Edition (Android)
- [Preloader Android](https://github.com/LiteLDev/preloader-android)

## Disclaimer

This mod is intended for Minecraft Bedrock Edition on Android. Compatibility may vary depending on the Minecraft version.
